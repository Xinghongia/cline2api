# 2026-09-25 前端二轮整改：配色收敛 + 布局重排（Graphite Indigo v2）

## 背景

Midnight Aurora 上线后用户反馈三点：①配色花里胡哨很难看；②布局没调，页面乱；
③账号/模型管理太粗糙。本轮针对性整改，主题从「紫青极光」换成「Graphite Indigo」。

## 改动

### 1. 配色收敛（设计系统 v2，frontend/design.md 已重写）

- 去掉：紫青渐变对、主按钮流光、卡片悬停光晕、极光背景、点阵纹理、渐变 logo、
  状态点呼吸动画、多彩 Tag
- 换成：中性石墨 OKLCH（色相 260、 chroma ≤0.006）+ **唯一靛蓝强调色**
  （dark `oklch(70% 0.12 268)` / light `oklch(52% 0.16 268)`），颜色只出现在
  交互态和状态语义上
- antd hex 映射同步（main.tsx），图表改单色系（accent + 灰阶，透明度 ≤55%）

### 2. 布局重排（页头/工具栏/数据三层体例，写入 design.md）

- **账号管理**：页头只留「OAuth 登录(主)/手动添加/批量导入/⋯」，
  导出/刷新全部/测试全部/清空收进 Dropdown（清空改二次确认弹窗）；
  新增工具栏：搜索（邮箱/ID）+ 状态筛选 + 右侧池子汇总 chips（共/活跃/冷却/失效）；
  数值列右对齐等宽、状态改彩点 pill、最近使用列可排序
- **模型管理**：页头只留「默认模型/添加模型」；工具栏 = 搜索 + 计费筛选 + 来源筛选
  （来源选项从数据动态生成）+ 右侧「从 Cline 同步/从 Zen 同步」；
  元信息行「上次同步 · 共 N · 显示 M」；计费/来源列改等宽文本与 pill
- 仪表盘/登录页同步收敛；其余页经令牌与皮肤层自动继承

### 3. 管理功能补强

- 账号：搜索、状态筛选、汇总统计、按调用次数/Tokens/最近使用排序、无邮箱时显示账号 ID 前缀
- 模型：搜索、计费/来源筛选、筛选计数展示

## 验证

构建全绿，服务重启后截图验收：账号页/模型页/深浅两套仪表盘均符合新体例
（截图存 .zcode/shots/v2-*.png）。主题切换、中英文不受影响。

## 经验

- 视觉重设计先问「多克制」再问「多有特色」——用户说"要有特色"不等于"要彩色"，
  对工具型产品，克制的单色 + 信息密度本身就是特色。
- 布局和配色是两件事，重设计必须各自明确验收，不能拿配色升级顶替布局整改。

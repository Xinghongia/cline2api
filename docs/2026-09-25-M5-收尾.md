# 2026-09-25 M5：收尾——代码分割、健康徽标、成本估算、README 汇总、桌面端验证

## 背景

重构的最后一个里程碑（M0 基建 → M1 前端 → M2 目录重组 → M3 统计 → M4 提供商 → **M5 收尾**）。目标：把各里程碑遗留的收尾项一次清完，并对整条构建链做最终验证。

## 改动范围

### 1. 前端路由级代码分割

- `App.tsx`：10 个页面全部改为 `lazy(() => import(...))` + `<Suspense>` 兜底
- 效果：主包 613KB → **234KB** gzip（-62%）；ECharts（183KB gzip）只随 Dashboard 按需加载；其余页面各自 3-27KB chunk
- 管理 UI 内嵌于单文件二进制的体验不变（所有 chunk 仍在 dist 内一起嵌入）

### 2. provider 健康徽标

- `providers.CooldownSnapshot()`：导出冷却状态只读副本（providerID:model → 截止时间）
- `GET /admin/api/providers` 响应增加 `cooldowns`（仅返回仍在冷却中的条目）
- 前端提供商表格：冷却中的提供商显示橙色「冷却 N」徽标，Tooltip 列出具体模型与恢复时间

### 3. 模型单价与成本估算

- `proxyconfig` 新增 `ModelPrices`（存 `.cline-config.json`，独立于模型同步，**不会被远程同步覆盖**）
- 新端点 `POST /admin/api/models/price`（id + 双向单价 USD/1M tokens；全零清除）
- `GET /admin/api/models` 响应带 `prices`
- `GET /admin/api/stats/summary` 新增 `estimatedCost`：按模型分组的 in/out 用量 × 单价（从小时桶聚合，SQL 精确到模型粒度）
- 前端：模型页新增单价列，"上下文"弹窗扩展为可同时编辑单价；Dashboard 趋势卡显示 `≈$X.XXXX`

### 4. README 汇总（中英）

- 功能清单全面更新（中转站/SQLite 统计/Key 管理/图表/ECharts/出口代理）
- 数据文件表：新增 `usage.db`、`.cline-providers.json`、`.cline-config.json`（含单价），标注 Key 对象格式自动兼容旧字符串
- 项目结构：cmd/ + internal/ 十二包（M2 已更新）

### 5. 构建链最终验证

- **桌面端实机构建通过**：`desktop/build.sh` 产出 `cline-proxy-desktop.exe`（20MB 单文件，前端已嵌入，版本号 git 自动推导 v1.6.3-18-g…），`-selfcheck` 通过（含新增的 `/admin/` 探活）
- `go test ./...` 九包全绿、`go vet` 干净、gofmt 无差异
- `.gitignore` 补 `usage.db` / `usage.db-wal` / `usage.db-shm`

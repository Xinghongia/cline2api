# 2026-09-25 M1：前端功能对齐——React 管理后台全量落地，旧 UI 退役

## 背景

M0 完成工程基建后，M1 的目标是把 9 个占位页全部做成真页面，**完整覆盖旧版 `admin_html.go`（2739 行内嵌字符串）的全部能力**，然后删除旧 UI。本里程碑只消费后端现有 39 个 `/admin/api/*` 接口，后端行为零改动。

## 改动范围

### 新增（frontend/src/）

- `api/types.ts`：与后端响应一一对应的类型定义（Account/Model/RequestLog/CustomProvider/OpencodeConfig/Stats 等，字段名以 curl 实测为准）
- `utils.ts`：fmtNum/fmtTime/copyText/openExternal/parseTokenLines
- `components/PageHeader.tsx`：统一页头（标题+副题+操作区）
- `pages/` 10 个页面：
  - **Login**：密码门（后端 `requireAdminAuth` 启用密码后 401 触发）
  - **Dashboard**：账号池统计卡（总数/活跃/冷却/失效）、累计请求、Token 四项、opencode 今日用量、运行时信息；10 秒自动刷新
  - **Accounts**：表格（状态徽标含冷却截止时间提示、用量排序、分模型用量展开行）+ 7 个操作：手动添加、OAuth 设备授权（2 秒轮询，结束自动入池）、批量导入（粘贴/文件/SSO Cookie 三 Tab，客户端解析 token 行/JSON 数组）、导出下载、刷新全部 Token、测试（单个/全部，结果弹窗）、清空（危险确认）
  - **Logs**：游标分页 + 加载更多，展示四项 Token、耗时、TPS、完成/失败（错误 Tooltip）
  - **Models**：模型表格（自定义/来源/计费徽标）、默认模型下拉直达 `config/update`、Cline/Zen 双同步、添加/删除自定义模型、上下文窗口与最大输出编辑
  - **Providers**：CRUD + 启停开关 + 连通性测试（先暂存再测保证测的是表单当前值）+ 预设填充 + 自定义请求头 Form.List
  - **Upstreams**：双 Tab——opencode Zen 全配置（启停/key/baseURL/并发/重试/故障转移三参/出口代理/策略/冷却展示/模型同步）、Cline 出口代理池
  - **Keys**：API Key 列表（脱敏显示+复制+删除）、生成（弹窗一键复制）、管理后台密码设置/清除
  - **Settings**：轮询策略、仅免费开关、免费模型链（多选保序）、上游请求头 KV 编辑、监听地址（含本机 IP 检测）
  - **About**：版本/监听/数据文件路径/仓库链接
- `App.tsx` 重写：认证门（首次探测 `/config`，全局 401 事件兜底）+ 真实路由
- `locales/en.json`：209 个 key 全量英文词条；**中文走 `t(key, '中文默认')` 内联默认值**，zh.json 只保留导航等骨架词

## 关键决策

1. **中文内联默认值 + en.json 映射**：`t('key', '中文')` 模式让中文永不缺词（i18next defaultValue），英文词条集中管理；与旧版"中文为源、英文映射"的思路一致但 key 化更规范。
2. **页面重组与旧 UI 的映射**：旧「路由与模型」页拆为「模型管理」（模型 CRUD+默认模型）与「设置」（策略/免费链/headers/监听）；旧「上游服务」的 providers 子 Tab 升级为独立导航页。功能无删减。
3. **OAuth 轮询副作用放 useEffect**：初版把"轮询结束处理"写在渲染体里（React 反模式，会触发"render 期间 setState"警告），已修正。
4. **Provider 测试语义**：测试前先静默保存（自动补 id），保证"测的就是表单里的值"；这是旧 UI 没做到的（旧 UI 测的是上次保存的值）。
5. **构建体积**：单 bundle gzip 430 KB（antd+echarts 全量内嵌于二进制），对本地服务可接受；代码分割留给 M5 优化。

## 踩坑与修复

1. **antd Table render 签名**：`(value, record, index)` 固定三参，不能像旧代码那样自定义第二参含义（Accounts 状态列），改为 `(status, row) => statusTag(status, row.cooldownUntil)`。
2. **Vite emptyOutDir 删占位文件**：M0 已在 build script 里补 `.gitkeep`，本里程碑沿用。
3. **i18next 插值调用形式**：`t(key, default, options)` 三参重载行为不确定，统一改为 `t(key, { defaultValue, ...vars })`。
4. **strict TS 的 noUnusedLocals**：Providers/Upstreams 初稿有未使用 import/错误 prop，tsc 全部拦下——严格模式值得。
5. **后台链导致的验证假失败**：`go build && go test && start &` 用 `&` 整链后台化，`sleep 4` 时服务还没起，curl 000。改为仅后台化启动命令本身。
